# AlgoLearn

AlgoLearn is an educational web application for learning and practicing algorithms through curated problems and interactive rooms.

Purpose
- Provide a concise set of algorithmic problems with examples and test cases.
- Offer an interactive frontend where learners can view problems and work on solutions.
- Support collaborative or isolated 'rooms' to discuss and solve problems together.

Key components
- Backend: TypeScript/Node server that serves problem data and APIs (see `backend/`).
- Frontend: Angular application that provides the landing page, problem UI, and room interfaces (see `frontend/`).
- Problems: Example problem definitions stored as JSON under `backend/problems/`.

Highlights
- Focused on learning algorithms and problem-solving patterns.
- Lightweight JSON-backed problem format for easy additions and testing.
- TypeScript across frontend and backend for type safety and consistency.

Where to look
- Backend entry: backend/server.ts
- Frontend app: frontend/src/app
- Problems: backend/problems
